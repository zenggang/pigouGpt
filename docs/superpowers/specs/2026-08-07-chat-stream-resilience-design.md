# Pigou AI 文本流稳定性修复设计

## 背景与根因

2026-08-07 线上出现 GPT-5.6 问答长期停在“思考中”的问题。现场证据表明：

- `chat.pigou.top`、Vercel 应用、ECS 数据库 API 和 MySQL 均可用。
- AI 请求通过 ECS nginx 转发到 `sub2api-bridge-chisel` 反向隧道后的 Sub2API。
- GPT-5.6 的最小请求超过 30 秒无响应，GPT-5.5 返回 nginx 502。
- 多条消息只保存了部分 reasoning summary 或“思考中...”，正文为空、`upstream_response_id` 为空，并永久停留在 `running`。
- 当前应用没有独立的上游连接超时和流空闲超时；Vercel 强制结束函数时无法保证写入最终错误状态。
- 上游 reasoning summary 会被直接展示，因而暴露英文 planning 文本。

## 目标

1. 恢复当前 Sub2API 反向隧道和后端服务的正常可用性。
2. GPT-5.6 上游连接失败或流长期无事件时，在 Vercel 300 秒上限前主动结束并展示明确中文错误。
3. 不自动切换 GPT-5.5 或 GPT-5.4，确保页面选择模型与实际回答模型一致。
4. 不再向用户展示上游英文 planning/reasoning summary；运行期间只展示通用“思考中...”，完成后只展示最终正文中显式生成的中文思路摘要。
5. 已遗留的普通文本 `running` 消息不再永久转圈；保留已有正文并标记中断，无正文时展示可重新生成的错误说明。

## 方案

### 远端服务恢复

先检查 ECS 的 nginx、chisel 隧道监听和远端 Sub2API 响应。对可控且确认异常的服务做最小范围重启，重启前记录进程状态，重启后验证监听端口、鉴权响应以及真实 GPT-5.6 请求。若隧道后的 Sub2API 后端不在当前 ECS 控制范围内，不伪造“已恢复”，应用侧仍必须完成失败兜底。

### 上游请求边界

为 `/responses` 增加两个独立边界：

- 连接/首响应超时：请求在限定时间内未建立有效响应时主动中止。
- 流空闲超时：连接建立后，连续一段时间没有任何 SSE 数据时主动中止。

超时统一转换为用户可理解的中文网关错误。HTML 502 页面不得原样拼入业务提示。日志记录模型、模式、阶段、耗时、HTTP 状态、request id 和是否已经输出正文，但不记录密钥或完整业务大对象。

### 流事件与消息收尾

服务端无论收到 `response.failed`、HTTP 错误、主动超时还是流读取异常，都发送规范化 `error` 事件，并强制把 assistant 快照保存为 `error`。只有收到正常完成事件或上游流正常闭合且无错误时才能保存为 `done`。

前端继续消费现有 SSE 协议；错误事件负责停止动画并展示错误。异常断流后即使没有收到 `done`，客户端最终收尾也不能把空消息伪装成“已完成”。

### 思考内容展示

不再转发 `response.reasoning_summary_text.delta` 和 `response.reasoning_summary_part.added` 的原始内容。服务端仍用通用“思考中...”表示进行状态；最终正文若包含显式的“思考过程/回答”结构，沿用现有解析逻辑提取可展示中文摘要。

### 存量消息恢复

普通文本 assistant 消息超过五分钟仍为 `running` 时，历史加载统一视为中断：

- 保留已经生成的正文。
- 清除不可展示的 reasoning 内容。
- 状态返回 `error`。
- 无正文时使用“上次请求已中断，可重新生成。”作为展示内容和错误原因。

发布后对当前线上已确认的陈旧 `running` 记录做一次有备份、按条件限定的状态修复，不影响图片任务或仍在五分钟窗口内的请求。

## 测试与验收

先补失败测试，再实现：

1. reasoning summary SSE 不产生可展示的 `thinking_delta`。
2. HTML 502 被规范化为中文通用错误，不泄露 HTML。
3. 上游连接超时和流空闲超时会产生错误并终止。
4. 陈旧普通文本 `running` 消息加载为可重试错误；图片任务和新请求不受影响。
5. 客户端异常断流不会把空 assistant 标记为成功。

本地验收执行专项脚本、现有全部 `verify:*`、ESLint、生产构建和 `git diff --check`。生产验收包括 Vercel 部署成功、首页和数据库健康、真实 GPT-5.6 简单问答、真实联网问答、错误路径在限定时间内结束、历史记录没有新增永久 `running`，以及现有生图链路不回归。

## 非目标

- 不把文本问答迁移为 ECS 异步任务。
- 不改变模型选择器和 GPT-5.6 默认值。
- 不静默降级到 GPT-5.5/5.4。
- 不调整与本故障无关的页面样式、会话结构或图片生成架构。
